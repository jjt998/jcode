# 会话事件 run_id 重复传参

## 发现日期

2026-09-07

## 问题现象

运行上下文压缩对比事件时出现错误：

```text
src.evidence.session_log.SessionEventBus.emit() got multiple values for keyword argument 'run_id'
```

## 根因

`JCodeAgent._emit_compact_context_events` 组装 `context_compression_compared` 的 payload 时包含 `run_id`，随后调用 `SessionEventBus.emit` 又显式传入同名参数。Python 在函数调用阶段拒绝两个同名关键字参数，事件无法写入，当前 run 被中断。

## 影响

- 上下文压缩对比流程会中断。
- 用户只能看到最终错误文本，控制台缺少异常堆栈，不利于定位。
