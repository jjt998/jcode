# 新会话区未显示模型推理配置

## 现象

Web 控制台打开一个尚未创建 session 的新会话区时，模型、推理和思考强度控件没有显示有效配置。选择已有 session 后，控件恢复正常。

## 根因

全局 `.jcode.toml` 已在 Web 服务启动时成功加载，后端 session 详情接口也能返回完整的 `model_profiles`。问题发生在前端初始化协议：`app.js` 只在 `selectSession()` 中读取模型档案，而空会话区没有 session 可供选择，因此前端从未获得全局模型配置。

## 影响

- 新项目或无 session 项目首次打开时，模型下拉框为空。
- 推理开关和思考强度没有可用值。
- 用户无法在首次发送前确认或调整新 session 的模型配置。

## 确认结论

这是 Web 新会话初始化链路缺失，不是 `.jcode.toml` 加载失败。
