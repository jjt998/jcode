# Todo 工具与描述加强设计

## 目标

将 todo 台账明确为会话级任务管理能力，状态仅允许 `pending`、`in_progress`、`completed`，并新增删除与归档操作；同时为全部工具补充模型可执行的用途、参数格式和失败语义描述。

## Todo 语义

- `todo_add` 新增任务。
- `todo_update` 更新已有任务字段；完成必须使用 `completed`。
- `todo_list` 只展示未归档任务及其进度。
- `todo_delete` 从当前台账永久移除任务，但不删除历史审计记录。
- `todo_archive` 保留任务记录并标记归档；归档任务不进入 active 列表、Working Memory 和最终完成门禁。本次不提供恢复归档。
- 任务状态不是生命周期字段，`archived` 不作为 status 值。

## 协议约束

状态字段使用严格枚举；工具 schema 与注册描述共同表达 exact 输入、来源要求、禁止结构和失败处理。删除与归档使用独立 runtime 工具，保持操作语义清晰。

## 持久化与审计

Todo ledger 保留归档项，并写入 `archived_at`；删除只改变当前 ledger。新增、更新、删除、归档均写入 session、Working Memory 和 session event。

## 验证

测试覆盖状态非法值拒绝、删除/归档后的列表与最终门禁行为、归档持久化、工具 schema 描述及所有工具注册描述的关键约束。
