# 会话后续发送未统一恢复工作区与执行环境

## 解决方案

- 启动恢复和已有会话后续发送统一调用 `build_resume_context()`。
- checkpoint 保存递归 workspace baseline 和 execution fingerprint。
- 后续 run 比较 `changed_paths`，通过现有 stale 标记入口标记旧读取证据。
- execution fingerprint 包含 Provider、模型、reasoning、协议和工具 schema hash。
- continuation 不兼容时只禁止继续旧原生链，不阻止创建新的 session continuation run。
- stale 不删除 history、artifact 或 Working Memory。
