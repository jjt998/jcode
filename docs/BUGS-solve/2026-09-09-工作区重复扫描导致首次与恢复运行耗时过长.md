# 工作区重复扫描导致首次与恢复运行耗时过长

## 解决方案

统一复用同一份 workspace baseline：

1. `CheckpointManager.create()` 只生成一次 baseline，再由 `Workspace.fingerprint_from_baseline()` 计算 fingerprint。
2. 会话延续评估只生成一次当前 baseline，并将该 baseline 传给 checkpoint 校验和 fingerprint 计算。
3. Harness timing 将一级 phase 与嵌套 detail 分开统计，避免父子 span 重复相加。

## 验证

新增 checkpoint 单测，确认生成 checkpoint 时 `baseline()` 只调用一次；恢复评估、Harness timing 及全量测试均通过。
