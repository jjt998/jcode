# 未发送历史元数据误触发四级压缩

## 修复日期

2026-09-09

## 修复方案

压力需求改为基于 `full_snapshot.serialized_input_tokens` 与固定输入快照的差值计算。压力计算、Provider 请求和上下文审计因此使用同一份序列化输入口径。

未发送的 History metadata 不再参与压力等级判断；最终容量校验逻辑保持不变。

## 验收

- 实际输入较小时，不会因未发送 metadata 误触发 Level 4。
- 压力审计仍保留 raw demand、flexible budget 和 pressure level。
- 压力、恢复、上下文和 Web 相关测试通过。
