# shell 快照漏记已有文件修改

## 解决方案

在 `Workspace` 增加统一的 `changed_paths(before, after)`：遍历前后路径并集，比较每个路径对应的 `(mtime_ns, size)`。

以下情况都进入 `changed_files`：

- 路径只存在于执行后快照。
- 路径只存在于执行前快照。
- 路径前后都存在，但 mtime 或大小变化。

ToolExecutor、父 Agent 的子任务外层快照和 WorkerManager 统一使用该方法，不再各自比较路径集合。

## 验证

增加已有文件经 shell 修改后进入 `changed_files` 的测试，并保留新增文件和失败后 partial success 的现有测试。
